This boots a real Linux kernel. The virtual PC runs in your browser using the open-source v86 emulator (WebAssembly). This page embeds the WebLinux demo as the first working kernel prototype while we integrate the emulator and boot images into this repository.
Networking: the guest can use a virtual Ethernet adapter and the demo's internet relay where available. It does not get direct control of your laptop's physical Wi-Fi adapter. GitHub Pages is static hosting, so this prototype requires no server of our own. If the embedded VM is blocked by browser policy, use “Open Linux separately”.
