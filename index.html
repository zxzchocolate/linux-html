What this is

A browser-hosted machine intended to run a compiled Linux kernel and initramfs. The kernel source remains in this repository; HTML and JavaScript provide the controls and emulator integration.

Networking

The guest needs a virtual NIC and a compatible networking backend. A web page cannot directly take control of your computer's physical Wi-Fi adapter.
